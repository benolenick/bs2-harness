## Criticism — what is still wrong, ranked

1. **The coverage DONE-gate has no input path (the fix in progress).** No mechanism
   ever marks a discovery ritual done: the trooper returns `facts: none` even after
   286-378s of real enumeration, because its VERDICT contract never tells it to report
   completed checks. Coverage froze at 5.26% (only the ritual's own marks) and the run
   could only end in `done_refused` after burning all 30 steps. Cartographer's
   `fold()` ALREADY handles `enum=<hint>:<ritual>` facts — the missing piece is only
   the trooper prompt. **Spec:** in live/trooper.py SYS_TMPL, extend the VERDICT facts
   examples with `"enum=80:dirs"` and add a MAP HYGIENE paragraph: report a check only
   when FINISHED, hint by PORT so each surface is marked exactly; vocabulary:
   ftp=anon-login,version-cve | ssh=version-cve,user-enum | smtp=user-enum-vrfy |
   dns=axfr,subdomain-brute | http=dirs,vhosts,params,tech-fingerprint,default-creds,
   js-endpoints,api-surface,source-exposure,auth-crawl | smb=shares,users,null-session |
   rpcbind=rpcinfo,nfs-shares | pop3/imap=creds-if-known. Then a unit test:
   fold(["enum=21:anon-login"]) marks the ritual and coverage pct advances.
2. **Memoria is keyed off the manager's fact blob, not the map.** It never fired in
   738 (memoria=False steps 1-3) even though the ritual KNEW vsftpd 3.0.3 / Apache
   2.4.41 from turn zero. It should key off map-node services/versions — recall should
   fire the moment the map names a service, before the manager thinks.
3. **Trooper objectives are still expensive and often fact-free.** Step 1: 286s/10
   cmds, step 2: 378s/11 cmds, both `facts: none` (auth wall). The cookbook exists but
   `GB_RECIPE_FIRST=0` (recipes are prompt-advisory only). Consider recipe-first per
   fingerprinted service (vsftpd 3.0.3 on 21 has a known anon/version card) instead of
   free-form objectives.
4. **No A/B benchmark.** "Leapfrog" is now evidenced (41s vs 1069s) but there is no
   harness comparing tools-on vs naked-manager on the same target. Until that exists
   the claim stays anecdotal.
5. **Lenz observer_blocked** — the observer cannot see runs; monitoring gap only.
6. **BS2 Terrain ← cartographer wiring still open** (Ben's own 08-24 flag) — the
   three battlestation servers running are other campaigns with `ariadne-url off`.
